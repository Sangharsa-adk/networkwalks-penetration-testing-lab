# Week 1 — Penetration Testing Lab Environment

## Objective

Build the initial penetration testing laboratory using Arch Linux as
the host operating system and Docker as the container platform.

The primary Week 1 task is to configure:

1. Kali Linux security environment
2. Windows 11 target environment
3. Shared Docker laboratory network

Additional security tools and automation components are documented under
Optional Work.

## Host Environment

- Host OS: Arch Linux
- Container platform: Docker
- Docker Compose used for multi-container configuration

## Primary Tasks

### 1. Kali Linux Docker Environment

Configure a Kali Linux rolling container for penetration testing and
security experimentation.

See:

[Docker Kali](./Docker-Kali/README.md)

### 2. Windows 11 Docker Environment

Configure a Windows 11 container as a controlled target environment.

See:

[Docker Windows](./Docker-Windows/README.md)
