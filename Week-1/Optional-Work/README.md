## Overview

Additional security, networking, development, and automation packages
were installed inside the Kali Docker environment.

These installations extend the basic Kali environment and prepare the
lab for future security exercises.

## Development

- Git
- Python 3
- pip
- Python virtual environments
- Python Tkinter

## Network and Security

- Nmap
- Netcat
- SMB client
- iputils-ping
- Metasploit Framework

## Python Network Automation

- Paramiko
- Netmiko

## Android Security

- Android Debug Bridge (ADB)
- apksigner
- zipalign

## General Utilities

- curl
- unzip
- jq

## Purpose

These tools provide the foundation for future:

- Network reconnaissance
- Penetration testing
- Network automation
- Security assessment
- Android security exercises
